# Fichas enriquecidas de producto

Una ficha por producto coordina negocio, experiencia, tecnología, datos, normativa, operación y aprendizaje. No se crean fichas paralelas por equipo: cada área agrega fuentes, estados y decisiones al mismo registro.

Para crear una ficha nueva:

1. copiar [`../templates/PRODUCT-SHEET.md`](../templates/PRODUCT-SHEET.md);
2. asignar un `product_id` estable;
3. completar todos los frentes, usando `por_validar` cuando no exista evidencia;
4. enlazar decisiones y fuentes, sin pegar transcripciones completas;
5. actualizar [`../INDEX.md`](../INDEX.md);
6. registrar qué documentos, contratos y pantallas necesitan propagación.

Las fichas semilla de esta carpeta resumen el material local vigente. No sustituyen revisión legal, de seguridad, de proveedor ni una nueva exportación de Notion.
